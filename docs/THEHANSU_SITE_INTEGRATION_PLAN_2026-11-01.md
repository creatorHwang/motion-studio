## 1. 결론

첨부 문서의 큰 방향은 채택한다.

- 고객이 사용하는 최종 주소는 `https://thehansu.net/motion/`
- Motion Studio에서 프롬프트 사서로 이동할 때 같은 출처의 `sessionStorage`를 사용
- 고객용 트렌드 화면은 `레이더+`로 단순화해 THE한수 안에 배치
- `finder.thehansu.net`은 데이터 수집·정규화 공급 계층으로 유지
- 펀딩 기간인 2026-11-03~2026-11-23에는 `thehansu.net` 본체를 수정하거나 배포하지 않음

다만 현재 운영 중인 `motion.thehansu.net`과 `finder.thehansu.net`을 즉시 제거하지 않는다. `/motion/` 탑재와 회귀검사가 완료될 때까지 기존 주소를 검증·복구 경로로 유지한다.

## 2. 현재 확인된 상태

### Motion Studio

- 운영 주소: `https://motion.thehansu.net/`
- GitHub 저장소: `creatorHwang/motion-studio`
- 현재 제품 파일은 정적 HTML·CSS·JavaScript로 구성됨
- `index.html`의 제품 자원 경로는 현재도 상대 경로임
- 외부 CDN이나 외부 폰트 로딩은 확인되지 않음
- `localStorage`와 `sessionStorage`를 아직 사용하지 않음
- Finder에서 `topic`, `category`를 공개 URL 값으로 받아 조합기에 적용함
- 상단 이동 버튼은 현재 `파인더`, `프롬프트 서재` 용어와 외부 주소를 사용함
- 영문 프롬프트에 사용자가 입력한 한국어 피사체·장면이 그대로 섞이는 문제가 있음

### 통합 파인더

- 운영 주소: `https://finder.thehansu.net/`
- 영상 선택 시 현재 `https://motion.thehansu.net/`을 새 창으로 열음
- 공개 주제명과 카테고리만 URL로 전달함
- 분석 초안은 Finder 출처의 `localStorage`에 저장되므로 THE한수 본체와 직접 공유되지 않음

### THE한수 본체

- 이 작업공간에는 THE한수 본체 소스가 없음
- GitHub 자동 배포가 아니라 사용자 PC의 배포 절차를 사용한다는 문서 설명만 확인함
- 실제 프롬프트 사서 입력 요소, 라우팅, 이용권 키 처리와 배포 스크립트는 11월 26일 편입 전에 Claude가 본체 소스에서 확인해야 함

## 3. 조정해야 할 결정

### 3.1 기존 서브도메인 유지

`motion.thehansu.net`은 `/motion/` 검증이 끝날 때까지 유지한다.

전환 순서:

```text
현재 운영 유지
→ dist/motion 패키지 생성
→ thehansu.net/motion/ 비공개 검증
→ 프롬프트 사서 왕복 검증
→ 고객 메뉴 노출
→ 안정화 후 서브도메인 리디렉션 여부 결정
```

서브도메인을 먼저 닫으면 편입 실패 시 즉시 복구할 주소가 사라진다.

### 3.2 서비스 간 전달 방식 분리

두 연결은 출처가 다르므로 같은 방법을 사용하지 않는다.

| 연결 | 출처 관계 | 전달 방식 |
|---|---|---|
| Finder → Motion | 다른 출처 | 공개 `topic`, `category`만 URL로 전달 |
| Motion → 프롬프트 사서 | 같은 출처 | `sessionStorage`의 `hansu_handoff` 사용 |

Finder의 전체 분석 근거 또는 API 키를 `/motion/` URL에 추가하지 않는다.

### 3.3 저장 키 접두사 예외

Motion 자체 저장 키는 `motion_` 접두사를 사용한다. 다만 `hansu_handoff`는 Motion과 THE한수 본체가 공동으로 읽는 서비스 간 계약 키이므로 명시적인 예외로 둔다.

수신 측은 한 번 읽은 직후 반드시 삭제한다.

## 5. 단계별 실행 계획

## 단계 1 — 펀딩 기간 준비 작업

기간: 2026-11-01~2026-11-23  
THE한수 본체 수정·배포: 금지

### 1A. Motion 영문 프롬프트 보정

권장 방식은 문서의 ①안이다.

- 한국어가 포함된 피사체·장면을 대괄호로 구분
- 영문 프롬프트 끝에 번역 안내 추가
- 입력이 완전한 영어라면 번역 안내를 붙이지 않음
- 한글·영문 혼합 입력은 한국어 포함으로 처리

검증:

- 한국어 입력
- 영어 입력
- 한글·영문 혼합 입력
- 빈 입력과 기본값
- 기존 국문 프롬프트 회귀

### 1B. `/motion/` 정적 패키지 생성

- `dist/motion/` 전용 빌드 명령 추가
- HTML·CSS·JavaScript·JSON만 포함
- 자원 경로는 `./` 기준으로 통일
- `/motion/` 아래의 HTTP 서버에서 직접 실행
- 루트 `/`에 의존하는 링크와 자원 요청이 없는지 검사
- 기존 `.pages-dist` 빌드는 서브도메인 검증용으로 유지

결과물 예시:

```text
dist/motion/
├─ index.html
├─ styles.css
├─ composer.css
├─ app.js
├─ handoff.js
└─ motions.json
```

### 1C. 브랜드 적용

- 밝은 종이색을 전체 기본 배경으로 적용
- 지정된 초록·크림·주황 색상 토큰 사용
- 캔버스 내부의 어두운 배경은 유지 가능
- 고객 노출 용어를 `레이더+`, `프롬프트 사서`, `Motion Studio`로 변경
- 실제 로고 파일을 받기 전까지 임시 로고를 만들지 않음
- 로고 영역은 텍스트 브랜드로 유지하거나 자리를 예약

### 1D. Motion → 사서 송신 기능

Motion에서 다음 팝업을 제공한다.

1. 국문 또는 영문 프롬프트 선택
2. 전달될 내용 미리보기
3. `사서에게 다듬기` 실행
4. `hansu_handoff` 저장
5. 같은 탭에서 `/?go=polish&from=motion`으로 이동

데이터 계약:

```json
{
  "v": 1,
  "from": "motion",
  "at": "ISO-8601",
  "lang": "ko",
  "topic": "최대 120자",
  "motionId": 11,
  "motionName": "FPV 드론 숏",
  "prompt": "최대 8000자"
}
```

보안 원칙:

- 본문을 URL에 넣지 않음
- API 키·토큰·내부 ID를 객체에 넣지 않음
- 잘린 값이 있으면 사용자에게 알림
- 저장 실패 시 이동하지 않고 원인을 안내
- 현재 `motion.thehansu.net`에서는 다른 출처이므로 실제 사서 연동 버튼을 활성화하지 않음
- `/motion/` 또는 로컬 동일 출처 통합 시험에서만 전체 흐름을 활성화

### 1E. 임시 수신 시험 페이지

THE한수 본체를 건드리지 않고 Motion 저장소 안에 테스트 전용 수신 페이지를 만든다.

- `hansu_handoff` 읽기
- 스키마 검증
- 한 번 읽은 뒤 삭제
- 정상·빈값·초과·이상 언어·만료 데이터 테스트
- 운영 빌드에는 포함하지 않음

## 단계 2 — 레이더+ 문서·시안

기간: 2026-11-01~2026-11-23  
구현 범위: 문서와 정적 시안만

### 고객 화면

고객에게는 세 영역만 우선 노출한다.

1. 오늘의 콘텐츠 기회

기술 상태와 할당량은 고객 화면에서 숨기고 관리자 화면에 유지한다.

- 수치가 성공을 보장하지 않는다는 안내 제공
- 근거는 접힌 영역에서 원천·단위·수집 시각과 함께 표시

### 시안 산출물

- 실제 API 호출 없음

## 단계 3 — `/api/plus` 계약 확정

기간: 2026년 11월 문서화, 12월 구현 검토

### 공개 경계

- 고객 브라우저는 `thehansu.net/api/plus/*`만 호출
- `finder.thehansu.net/internal/plus/*`는 서버 간 호출만 허용
- `X-Plus-Secret`은 양쪽 Cloudflare secret에만 저장
- 브라우저 JavaScript, 문서, 로그와 채팅에 비밀값을 기록하지 않음
- THE한수 Worker는 성공 응답을 최대 30분 캐시
- 원천 하나가 멈춰도 나머지 원천 데이터는 반환

### 계약 문서에 추가할 항목

- 엔드포인트 목록
- 요청·응답 JSON Schema
- 오류 코드
- `null` 처리 규칙
- `sourceStatus` 값 목록
- 카테고리 매핑표
- 캐시 키와 만료 정책
- 서버 시각과 수집 시각의 구분
- 스키마 버전 호환 정책

운영 D1 마이그레이션과 secret 등록은 별도 승인 전 실행하지 않는다.

- 사서에게 다듬기 왕복 가능
- 수신 데이터 한 번 사용 후 삭제
- 기존 이용권·책갈피·방문 통계 정상
- 운영 배포와 테스트 결과가 구분되어 보고됨

### 레이더+ 완료

- 고객 브라우저는 THE한수 API만 호출
- Finder 내부 API는 secret 검증
- 원천별 값·단위·수집 시각 보존
- 실시간 YouTube 검색을 고객에게 노출하지 않음
- 장애 원천을 표시하면서 나머지 결과 제공
